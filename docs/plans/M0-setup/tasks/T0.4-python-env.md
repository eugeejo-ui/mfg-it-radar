# T0.4 파이썬 환경 — 작업 계획서

- 상태: 완료
- 상위 문서: `docs/plans/M0-setup/phase-plan.md`

## 목적

- Anaconda 기본 환경과 분리된 프로젝트 전용 가상환경을 만들고, 앱용과 파이프라인용 패키지 버전을 고정함
- Streamlit Community Cloud가 읽는 `requirements.txt`는 앱에 필요한 것만 담아 배포를 가볍게 함

## 입력

- Anaconda Python 3.11.7 (`python --version`으로 확인함)
- 전체 계획 3장 (`requirements.txt` 앱용, `requirements-pipeline.txt` 파이프라인용)
- 로컬에 설치된 Streamlit 1.62.0 (기획 단계에서 확인)

## 절차

1. `python -m venv .venv`
2. `.venv\Scripts\python -m pip install --upgrade pip`
3. 패키지 설치 (PyPI)
   - 앱: streamlit==1.62.0, pandas, pyarrow, seaborn, matplotlib
   - 파이프라인: openpyxl, requests, python-dotenv, pytest
4. 설치된 실제 버전을 확인해 두 파일에 `==`로 고정함
   - `requirements.txt`: 앱 패키지
   - `requirements-pipeline.txt`: `-r requirements.txt` + 파이프라인 패키지
5. pandas가 3.x로 설치되면 KISA 2026 파일을 읽어 행 수·열 형식을 확인함. 문제가 있으면 2.x로 낮춰 고정함
6. `.env.example` 작성: `DART_API_KEY=` (값 없음)

## 산출물

- `.venv/` (커밋 안 됨), `requirements.txt`, `requirements-pipeline.txt`, `.env.example`

## 검증 방법

- `.venv\Scripts\python -c "import streamlit, pandas, pyarrow, seaborn, matplotlib, openpyxl, requests, dotenv, pytest"` 성공
- `.venv\Scripts\python`으로 KISA 2026 파일을 읽어 826행, IT 투자액 열이 숫자형임을 확인
- 새 가상환경에 `requirements-pipeline.txt`로 다시 설치해도 같은 버전이 설치됨 (고정 확인)
