# T0.1 저장소 초기화 — 작업 계획서

- 상태: 완료
- 상위 문서: `docs/plans/M0-setup/phase-plan.md`

## 목적

- 프로젝트 폴더를 git 저장소로 만들고, 공개 저장소에 올리면 안 되는 파일(원본, 키, 가상환경, 캐시)을 처음부터 제외함

## 입력

- `C:\mfg-it-radar` (현재 `docs/`만 있음)
- 전체 계획 2장·3장 (원본은 커밋하지 않음, 법인등록번호가 들어갈 수 있는 로컬 캐시도 커밋하지 않음)

## 절차

1. `git init -b main`
2. 로컬 설정 `core.quotepath false` (한글 파일명을 이스케이프 없이 표시)
3. `.gitignore` 작성
   - `data/raw/*` 제외, 단 `data/raw/manifest.csv`는 추적
   - `data/cache/` (연간 로컬 빌드 캐시, 법인등록번호가 들어갈 수 있음)
   - `.env`, `.venv/`, `__pycache__/`, `*.pyc`, `.pytest_cache/`, `.streamlit/secrets.toml`, `*.log`, OS 파일(`Thumbs.db`, `.DS_Store`)
4. `.gitattributes` 작성: 텍스트 줄바꿈 자동 처리, parquet·xlsx·png는 바이너리
5. `README.md` 작성: 서비스 설명 한 단락, 문서 위치, 현재 단계

## 산출물

- `.git/`, `.gitignore`, `.gitattributes`, `README.md`

## 검증 방법

- `git status`가 동작하고 브랜치가 main임
- 검증용 임시 파일로 확인: `data/raw/x.xlsx`는 무시되고 `data/raw/manifest.csv`는 무시되지 않음 (`git check-ignore -v`)

## 진행 기록

- 2026-09-28 `git init -b main`, `core.quotepath false` 설정함
- `.gitignore`, `.gitattributes`, `README.md` 작성함
