# T0.6 GitHub 저장소 생성과 첫 푸시 — 작업 계획서

- 상태: 진행 중
- 상위 문서: `docs/plans/M0-setup/phase-plan.md`
- 사용자 확인: 2026-09-28 저장소 이름 `mfg-it-radar`, 공개 저장소로 승인받음

## 목적

- M0 결과를 공개 저장소 `eugeejo-ui/mfg-it-radar`에 올려, M5·M6 자동 갱신과 M2 Cloud 배포의 기반을 만듦
- 원본 파일, 키, 가상환경, 개인정보가 저장소에 섞이지 않게 함

## 입력

- T0.1~T0.5, T0.7 산출물
- gh CLI 로그인 (eugeejo-ui, repo·workflow 권한)

## 절차

1. 스테이징: `git add -A`
2. 푸시 전 점검
   - `git ls-files`에 `data/raw/`의 원본 파일, `.env`, `.venv/`, `data/cache/`가 없음 (`data/raw/manifest.csv`만 있어야 함)
   - 추적 파일 전체에서 키·법인등록번호처럼 보이는 문자열 검색
     - 40자리 영숫자
     - 13자리 숫자 (manifest의 sha256·크기 값은 제외하고 봄)
   - 추적 파일 크기 확인 (1MB 넘는 파일이 없어야 함)
3. 첫 커밋: M0 산출물 요약 메시지
4. `gh repo create mfg-it-radar --public --source . --remote origin --push`
5. 원격 확인: `gh repo view`, 원격 파일 목록에 원본이 없는지 확인

## 산출물

- 원격 저장소 `https://github.com/eugeejo-ui/mfg-it-radar` (공개)
- 첫 커밋

## 검증 방법

- `git status`가 깨끗하고, `git log origin/main`에 첫 커밋이 있음
- 원격 파일 목록(`gh api` 트리 조회)에 원본 10개와 `.env`가 없음
