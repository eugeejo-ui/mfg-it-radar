- 상위 문서: `docs/plans/M0-setup/phase-plan.md`

## 목적

- 서비스 명세를 프로젝트 안에 두어 Downloads 파일이 없어져도 기준 문서가 남게 함
- 진행 문서 규칙과 데이터 원칙을 `CLAUDE.md`에 적어 다음 세션에서도 같은 방식으로 작업하게 함

## 입력

- `C:\Users\조유신\Downloads\SPEC.md`
- 전체 계획 1장(결정), 4.1장(정제 규칙), 10장(진행 문서 규칙)
- SPEC 5장(화면 설계 원칙), 14장(작업 규칙)

## 절차

1. `Downloads\SPEC.md` → `docs/spec/SPEC.md` 복사 (내용 변경 없음). sha256으로 원본과 같은지 확인
2. `CLAUDE.md` 작성
   - 프로젝트 한 줄 설명, 문서 위치
   - 진행 문서 규칙 (전체 계획 10장 요약)
   - 데이터 원칙 (비노출 항목, 원본·키 커밋 금지, 재무 기준 혼용 금지, 값 없음과 0 구분, 점수·순위 없음)
   - 작업 주의 (한글 경로, 가상환경 파이썬 명시, DART 키 취급)
   - M2는 Stitch 핸드오프

## 산출물
