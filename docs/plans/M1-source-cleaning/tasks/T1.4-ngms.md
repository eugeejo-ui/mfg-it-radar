# T1.4 배출권 정제 — 작업 계획서

- 상태: 완료
- 상위 문서: `docs/plans/M1-source-cleaning/phase-plan.md`

## 목적

- 배출권거래제 할당대상업체 772곳을 `emission_target`으로 정제해, 규제 노출 블록·세부업종 보완·후보 필터에 씀

## 입력

- `ngms_emission` (manifest), `pipeline.normalize`
- 사전 점검 (2026-09-28)
  - `header=0, skiprows=[1]`로 읽으면 772행. 첫 열(`Unnamed: 0`)은 전부 빈 값
  - 업체명 결측 0, 업체코드 고유
  - 업체코드는 I 506, E 131, M 99, F 29, S 7곳으로 시작하는 11자리 문자 (IA…처럼 앞글자가 두 개인 경우 있음). `docs/data-sources.md`의 "E + 10자리" 설명은 틀림 → T1.8에서 고침
  - KSIC는 숫자형, 4자리 3건

## 절차 (TDD)

1. `clean_emission(raw)`
   - 이름이 `Unnamed`로 시작하는 빈 열과 `NO` 열을 버림
   - 열: `company_code`, `company_name`, `name_key`, `ksic5`(`ksic5_from_ngms`), `ksic2`
2. `load_emission()`: 원본 읽기 + 정제
3. 테스트
   - 가짜 데이터: 빈 열 제거, KSIC 앞자리 0 복원, 이름키
   - 원본 회귀: 772행, 업체코드 고유, 이름키 중복 0, 0으로 시작하는 KSIC 3건, 제조업(중분류 10~34) 451곳

## 산출물

- `pipeline/sources/ngms.py`, `tests/test_ngms.py`

## 검증 방법

- 새 테스트가 구현 전에 실패하고 구현 후 통과함 (`-W error`)

## 진행 기록

- 2026-09-28 사전 점검에서 업체코드 형식이 참조 문서 설명("E + 10자리")과 다름을 발견함 (입력 절 참고)
- 테스트를 먼저 씀 (`tests/test_ngms.py` 3개). 실행하니 `ngms` 모듈이 없어 실패함 → 기대한 실패
- 구현 후 전체 111 passed (`-W error`)
- 첫 빈 열은 위치(`iloc[:, 1:]`)가 아니라 이름(`Unnamed`로 시작)으로 버림 → 원본 열 순서가 바뀌어도 안전함

## 결과

- 상태: 완료
- 원본 회귀 모두 일치
  - 772행, 업체코드 고유, 이름키 중복 0
  - 0으로 시작하는 KSIC 3건 (앞자리 0 복원 확인)
  - 제조업(중분류 10~34) 451곳
