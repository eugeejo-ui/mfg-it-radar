# 데이터 결합 스키마 — 제조업 IT 투자 레이더

## 0. 이 문서의 용도

- 원본 데이터 7종(DART 포함)이 회사를 어떻게 식별하는지, 어떤 경로로 한 회사에 모이는지 정리함
- 결합 후 회사 1곳당 확보되는 정보와 제조업 387개사 기준 확보 수를 적음
- 수치는 2026.9.28 원본 파일 점검 결과임. 회사명 정규화는 SPEC 7장 규칙을 그대로 씀
- DART 결합률은 API 키로 기업 고유번호 목록을 받은 뒤 측정함 (8장)

## 1. 연결 구조

모든 원본에 공통으로 들어 있는 키는 없음. DART 고유번호(corp_code)를 기업 마스터의 기본키로 두고, 나머지 원본을 네 가지 경로로 붙임.

```
[정확 결합]  키 값이 같으면 같은 회사
  공정위 기업집단별 개요 ──기업집단명──▶ 공정위 소속회사 개요 ──법인등록번호 = jurir_no──▶ 기업 마스터

[이름 결합]  회사명 정규화 → 대응표(사람 검수) → corp_code
  KISA 정보보호 공시 2025·2026 ──────▶ 기업 마스터
  NGMS 배출권 할당대상 ──────────────▶ 기업 마스터
  산단공 전국 등록공장 (회사당 N행) ───▶ 기업 마스터

[DART 조회]  corp_code로 API 호출
  기업 마스터 ──▶ 기업개황 · 재무 · 공시목록 · 직원현황

[지역]  기업 키 없음, 시도 단위로만 연결
  산단공 등록공장의 시도 ──시도──▶ 산단공 시도별 통계 4종
```

## 3. 기본키를 corp_code로 두는 이유

- DART 자동 갱신에 쓰는 API(기업개황, 재무, 공시검색, 직원현황)가 모두 corp_code로 조회함
- 기업개황의 jurir_no(법인등록번호)로 공정위 소속회사와 정확히 이어짐
- 회사명이 바뀌어도 corp_code는 유지됨. 정보보호 공시 2026 중 89곳은 2025와 이름이 달라 연도 간 연결이 끊기는데, 이 가운데 이름만 바뀐 회사는 corp_code로 다시 이어짐
- 공개해도 되는 식별자라 기업 브리프 주소(`?corp=`)에 쓸 수 있음. 법인등록번호·사업자등록번호는 SPEC 5장에 따라 결합에만 쓰고 화면에 노출하지 않음

## 4. 정보보호 공시를 corp_code에 붙이는 경로

- 정보보호 공시에는 법인번호가 없어서 어느 경로든 이름 결합이 한 번은 들어감
- 경로 1: 정보보호 이름 = 소속회사 이름 → 법인등록번호 → DART jurir_no → corp_code
  - 제조업 125곳이 해당함
  - 이름을 비교하는 대상이 3,521개사로 좁아 동명 오결합 위험이 낮음
- 경로 2: 정보보호 이름 = DART corp_name → corp_code
  - 나머지 제조업 262곳이 해당함
  - DART에 등록된 법인 전체와 비교하므로 동명 후보가 여럿 나올 수 있음. 상장 여부, 제조업 업종코드(10~34), 본사 주소로 후보를 좁히고 사람이 검수함
- 결합 결과는 대응표(xwalk)에 남기고, 매년 갱신 때 확정된 대응을 재사용함

## 7. 결합 품질 주의

- 공장: 회사당 공장 수가 튀는 이름(대원산업 58, 태광산업 31, 우리산업 31, 에스텍 23)은 동명 회사가 섞였을 가능성이 큼. 공장 20곳 이상, 생산품이 KSIC와 동떨어짐, 본사 시도와 공장 시도가 전혀 겹치지 않음 → 이 중 하나라도 해당하면 검수 대상으로 올림
- 소속회사 매출액 "0": 전체 3,539행 중 600행. 0과 값 없음을 구분해 저장함 (제조업 매칭 125곳은 모두 매출이 0보다 큼)
- 정보보호 공시 2026: 업종이 비어 있는 행 6개, 임직원 수가 소수로 적힌 행 있음
- 정보보호 공시 2025↔2026: 이름이 일치하지 않는 89곳은 신규 공시와 회사명 변경을 구분해야 함 → corp_code 결합 후 판별

## 8. DART 결합 전에 측정할 것

- DART 고유번호 목록(corpCode.xml)을 받아 정보보호 제조업 387개사의 corp_code 결합률 측정
- 공정위 소속회사 3,521개사의 법인등록번호와 DART jurir_no 일치율 측정
- DART 재무 API가 비상장 제조사 262곳 중 몇 곳의 매출을 주는지 확인
